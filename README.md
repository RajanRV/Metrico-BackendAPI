# Metrico Backend

Compliance Console API built with Express.js, Sequelize ORM, and PostgreSQL.

## Tech Stack
- Node.js + Express.js
- Sequelize ORM
- PostgreSQL

## Getting Started

### 1. Clone the repo
git clone <repo-url>
cd metrico-backend

### 2. Install dependencies
npm install

### 3. Setup environment
cp .env.example .env
# Fill in your values in .env

### 4. Run the server
npm run dev
